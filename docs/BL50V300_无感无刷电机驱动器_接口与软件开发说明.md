# BL50V300 无感无刷电机驱动器
## 接口、接线与 ESP32 软件开发说明

**文档用途：** 将商品详情图片中的信息整理为可供 Claude Code / Codex 读取的软件开发依据。  
**适用对象：** BL50V300 无霍尔、无感直流无刷三相电机驱动板。  
**目标平台：** ESP32-S3，ESP-IDF v5.5.4。  
**资料性质：** 本文“商品资料”部分来自卖家图片；“工程建议”部分为根据接口特性形成的设计建议。未给出的电气参数必须通过万用表、示波器或卖家确认，不能由软件自行假定。

# 1. 一页速查

## 1.1 关键参数

| 项目 | 商品资料给出的参数 |
|---|---|
| 产品名称 | BL50V300 无感无刷电机驱动器 |
| 适用电机 | 无霍尔直流无刷三相电机，连接 U/V/W 三相线 |
| 工作电压 | DC 6–50 V |
| 控制方式 | 0–5 V 模拟量调速 / PWM 调速，可通过板载按键切换 |
| PWM 要求 | 1–10 kHz，幅值 3.3–5 V |
| 峰值电流 | 35 A |
| 额定电流 | 12 V 时 25 A；24 V 时 12 A |
| 标称功率 | 300 W（商品标题；24 V × 12 A 约为 288 W） |
| 霍尔传感器 | 不需要，无霍尔/无感驱动 |
| 最大转速 | 商品标称 130,000 RPM，表示驱动器能力上限，不代表具体电机一定能够达到 |
| 外形尺寸 | 63 mm × 45 mm × 31 mm |

## 1.2 控制端子逻辑

| 端子 | 商品资料说明 | 软件抽象建议 |
|---|---|---|
| STOP | 默认高电平约 5 V；接 GND 停止 | `stop=true` 时将端子拉低 |
| BRAKE | 默认高电平约 5 V；接 GND 瞬间停止 | `brake=true` 时将端子拉低 |
| DIR | 默认高电平；接 GND 反转 | 方向逻辑必须允许配置，不能把“高=正转”写死到业务层 |
| GND | 控制信号地 | 与 ESP32 控制地共地 |
| 0-5V/PWM | 默认模拟量调速；切换到 PWM 后接受 1–10 kHz、3.3–5 V PWM | ESP32 LEDC 默认使用 5 kHz；0% 启动 |
| 5V | 约 5 V、100 mA 输出 | 仅作为小功率辅助输出，禁止与 ESP32 的 5 V 电源直接并联 |
| 13V | 约 13 V、100 mA 输出 | 仅作为小功率辅助输出，禁止接入 ESP32 GPIO |
| FG | 转速脉冲输出 | 输出电压、类型、脉冲数/转未知，默认不接 MCU，测量确认后再启用 |

## 1.3 推荐的 ESP32 接口结论

- `PWM`：ESP32 3.3 V PWM 可满足商品标注的 3.3–5 V 幅值要求；建议串联 220 Ω～1 kΩ，并加 10 kΩ 下拉，保证复位阶段为 0%。
- `STOP/BRAKE/DIR`：不建议直接连接 ESP32 GPIO。端子默认约 5 V，应使用 2N7002 等 N 沟道 MOSFET或 NPN 三极管做“开漏下拉”。
- `FG`：资料不足，未测量前禁止直连 ESP32。
- 必须共地：驱动器控制 GND 与 ESP32 GND 相连。
- 驱动器板载按键必须先切换到 PWM 模式；切换状态会保存，重新上电无需再次设置。

# 2. 产品概述

BL50V300 是面向无霍尔直流无刷三相电机的宽电压、大电流驱动器。驱动器完成三相换相，控制器只需要提供速度、方向、停止和刹车信号，不需要输出 U/V/W 三相 PWM。

商品资料列出的应用包括：无人机电机、水泵、油泵、气泵、电动工具、小型压缩机、吸尘器、暴力风扇和推进器等。

**软件开发中的重要理解：** ESP32 只控制低压控制端；电机 U/V/W 和主电源 VCC/GND 由驱动板直接处理。不要在 ESP32 程序中实现六步换相或 FOC。

# 3. 接口定义

## 3.1 主电源与电机端子

按商品图片从上到下/从标注识别：

| 端子 | 用途 | 注意事项 |
|---|---|---|
| GND | 主电源负极 | 与控制 GND 在系统中需要共地，但大电流回路应采用合理的星形接地/粗线连接 |
| VCC | 主电源正极 | DC 6–50 V；模块无反接保护，接反可能永久损坏 |
| W | 电机 W 相 | 接无刷电机三相线 |
| V | 电机 V 相 | 接无刷电机三相线 |
| U | 电机 U 相 | 接无刷电机三相线 |

电机方向的“正/反”定义受 U/V/W 相序和机械安装方向影响。软件应将方向定义设计为可配置项；方向与预期相反时，可先修改软件中的方向极性，必要时断电后交换任意两相。

## 3.2 控制端子

| 端子 | 电气/功能描述 | 推荐控制方式 |
|---|---|---|
| STOP | 默认高电平约 5 V，拉到 GND 后停止 | 开漏下拉，低有效 |
| BRAKE | 默认高电平约 5 V，拉到 GND 后快速/瞬间停止 | 开漏下拉，低有效 |
| DIR | 默认高电平，拉到 GND 后反转 | 开漏下拉，低有效；方向名称允许反相配置 |
| GND | 控制地 | 连接 ESP32 GND |
| 0-5V/PWM | 模拟量或 PWM 调速输入 | PWM 模式下由 ESP32 LEDC 输出 |
| 5V | 5 V 辅助输出，约 100 mA | 不作为大负载电源，不与其他 5 V 电源并联 |

## 3.3 辅助焊盘/接口

商品图标出了 `GND`、`FG`、`13V`：

- `13V`：约 13 V 输出，额定电流约 100 mA，供外部小功率设备使用。
- `FG`：转速脉冲输出，可用于转速表。
- `GND`：辅助接口地。

商品资料没有给出 FG 的高电平电压、输出结构（开漏/推挽）、每转脉冲数、最大频率和是否隔离。因此软件驱动应将 FG 功能设计为**可选且默认关闭**。

# 4. 调速模式

## 4.1 0–5 V 模拟量模式

板子上电默认可能处于 0–5 V 调速模式：

- 0 V：停止。
- 5 V：最大转速。
- 板载电位器可以调速。

本文的软件方案不使用模拟量模式。

## 4.2 PWM 模式

商品资料要求：

- PWM 频率：1–10 kHz。
- PWM 幅值：3.3–5 V。
- 通过板载按键切换调速模式。

按键操作：

1. 短按一次，指示灯闪三下：切换到 PWM 调速模式，立即生效并保存。
2. 再短按一次，指示灯闪一下：切换到 0–5 V 调速模式，立即生效并保存。
3. 模式会掉电保存，下一次上电不需要重新切换。

**推荐软件默认值：** PWM 频率 5 kHz，10 位占空比分辨率，初始化占空比 0%。5 kHz 位于 1–10 kHz 范围中部，给频率误差和兼容性留出余量。

**待实测项：** 商品资料未明确说明 PWM 占空比与速度是否严格线性、最低起转占空比、0% 是否与 STOP 完全等价。代码应提供启动斜坡和最小有效占空比配置，但默认不擅自设置非零最低占空比。

# 5. 推荐硬件接口（ESP32-S3）

## 5.1 STOP、BRAKE、DIR

这些输入默认约为 5 V，高电平为释放状态、接 GND 为动作状态。为防止 5 V 回灌 ESP32，推荐每一路使用 N 沟道 MOSFET开漏下拉：

```text
ESP32 GPIO ── 100Ω~1kΩ ── Gate  2N7002
                         Source ── GND
BL50 STOP/BRAKE/DIR ───── Drain
ESP32 GND ─────────────── BL50 GND
```

建议在 MOSFET Gate 增加 47 kΩ～100 kΩ下拉或按系统安全需求设计上电默认状态。

在上述推荐电路下：

- ESP32 GPIO 输出高：MOSFET 导通，BL50 输入被拉低，功能被“断言”。
- ESP32 GPIO 输出低：MOSFET 关断，BL50 输入恢复默认高电平，功能被“释放”。

代码中必须封装为逻辑 API，不允许业务代码直接写 GPIO 电平。

## 5.2 PWM

推荐连接：

```text
ESP32 PWM GPIO ── 220Ω~1kΩ ── BL50 0-5V/PWM
                                 │
                               10kΩ
                                 │
                                GND
```

- 商品资料明确接受 3.3–5 V PWM，因此 ESP32 3.3 V 输出可直接作为控制信号。
- 10 kΩ下拉用于保证 ESP32 复位或引脚高阻期间速度命令为 0。
- 如果实测发现输入端存在高于 3.3 V 的反向电压或干扰，应增加缓冲器、光耦或电平转换，不应继续直连。

## 5.3 FG

在确认以下信息前不要连接 ESP32：

1. FG 空载高电平电压。
2. FG 是开漏、集电极开路还是推挽输出。
3. 每转脉冲数。
4. 最大脉冲频率。

若实测确认 FG 为开漏输出，可使用 10 kΩ上拉到 3.3 V 后接 ESP32 PCNT/GPIO；若为 5 V 或 13 V 推挽输出，必须经过分压、缓冲或光耦。

## 5.4 电源与安全

- 模块无电源反接保护，必须确认极性后上电。
- 电源额定功率应大于电机额定功率，并考虑启动电流和刹车回馈。
- 示例：100 W、12 V 电机额定电流约为 8.3 A，电源持续电流不得低于该值，并应留出余量。
- 主电源、电机线使用与实际电流匹配的线径、保险丝和接线端子。
- 先接线，再上电。
- 首次测试使用限流电源、低电压、空载或轻载条件。

# 6. 软件控制语义

## 6.1 正常停止与刹车

根据商品描述：

- `STOP`：停止。
- `BRAKE`：瞬间/快速停止。

建议软件语义：

- 正常停止：速度斜坡降到 0%，然后断言 STOP。
- 紧急停止：立即将 PWM 设为 0%，断言 BRAKE；经过可配置短时间后转入 STOP 状态。

BRAKE 能否长期保持、是否导致电机或驱动器发热、是否把能量回灌电源，商品资料未说明。默认刹车脉冲时间可设为 200 ms，但必须由实机测试确定，不能视为厂家规定值。

## 6.2 改变方向

禁止在高速运行时直接切换 DIR。推荐顺序：

1. 速度斜坡下降到 0%。
2. 断言 STOP。
3. 等待电机完全停止，或至少等待配置的停机时间。
4. 设置 DIR。
5. 等待 20–100 ms 信号稳定。
6. 释放 STOP。
7. 按斜坡提升到目标速度。

## 6.3 启动顺序

1. 初始化 GPIO，PWM 占空比保持 0%。
2. 断言 STOP。
3. 释放 BRAKE。
4. 设置初始方向。
5. 初始化 LEDC，确认 PWM 输出为 0%。
6. 完成系统自检后释放 STOP。
7. 根据目标速度执行软启动斜坡。

# 7. ESP-IDF 驱动组件要求

## 7.1 推荐目录

```text
components/bl50v300/
├── CMakeLists.txt
├── include/
│   └── bl50v300.h
└── bl50v300.c
```

可选测试代码放在：

```text
main/bl50v300_test.c
```

不要把测试逻辑混入正式驱动文件。

## 7.2 配置结构建议

```c
typedef struct {
    gpio_num_t stop_gpio;
    gpio_num_t brake_gpio;
    gpio_num_t dir_gpio;
    gpio_num_t pwm_gpio;
    gpio_num_t fg_gpio;              // GPIO_NUM_NC 表示禁用

    ledc_timer_t pwm_timer;
    ledc_channel_t pwm_channel;
    uint32_t pwm_frequency_hz;        // 默认 5000
    ledc_timer_bit_t duty_resolution; // 默认 LEDC_TIMER_10_BIT

    bool reverse_dir_logic;           // 修正机械方向/UVW相序差异
    bool use_open_drain_transistors;  // 默认 true，对应本文推荐接口
    uint32_t ramp_step_ms;            // 默认 20 ms
    float ramp_step_percent;          // 默认 1%~5%，由项目确定
    uint32_t brake_pulse_ms;           // 默认 200 ms，仅为工程初值
} bl50v300_config_t;
```

## 7.3 公共 API 建议

```c
esp_err_t bl50v300_init(const bl50v300_config_t *config);
esp_err_t bl50v300_deinit(void);

esp_err_t bl50v300_set_speed_percent(float percent);
esp_err_t bl50v300_set_direction(bl50v300_direction_t direction);
esp_err_t bl50v300_start(void);
esp_err_t bl50v300_stop(void);
esp_err_t bl50v300_brake(uint32_t duration_ms);
esp_err_t bl50v300_emergency_stop(void);

float bl50v300_get_target_speed_percent(void);
bl50v300_state_t bl50v300_get_state(void);
```

所有速度输入必须限制在 0.0%～100.0%。不得让调用方传入原始 LEDC duty。

## 7.4 状态机建议

```text
UNINITIALIZED
     ↓ init
STOPPED ←──────────────┐
  ↓ start              │ stop / brake finished
RUNNING ── brake ──→ BRAKING
  │
  └── fault ───────→ FAULT
```

最低要求：

- `UNINITIALIZED`：禁止任何控制。
- `STOPPED`：PWM=0，STOP 断言，BRAKE 释放。
- `RUNNING`：STOP/BRAKE 释放，PWM 根据目标速度输出。
- `BRAKING`：PWM=0，BRAKE 断言。
- `FAULT`：PWM=0，STOP 断言；只有显式复位故障后才能重新启动。

## 7.5 LEDC 参数

- ESP-IDF：v5.5.4。
- 芯片：ESP32-S3。
- 默认 PWM 频率：5,000 Hz。
- 默认分辨率：10 bit。
- duty 计算应使用分辨率上限，避免写死 1023。
- 初始化后立即写 0 duty 并调用 update。
- 调速模式由人工通过板载按键设置为 PWM；软件无法从现有资料判断当前模式。

## 7.6 并发与错误处理

- 驱动内部应有互斥保护，避免多个任务同时修改速度、方向和刹车状态。
- 所有 GPIO/LEDC API 返回值必须检查并向上返回。
- `init()` 重复调用应返回明确错误，或先安全 deinit。
- 任何配置错误都应保持 PWM=0、STOP 断言。
- 日志标签建议为 `BL50V300`。

# 8. Claude Code 编码约束

Claude Code 根据本文编写代码时必须遵守：

1. 使用 ESP-IDF 原生 `gpio` 和 `ledc` 驱动，不使用 Arduino API。
2. 目标版本固定为 ESP-IDF v5.5.4，不升级 IDF。
3. 不实现三相换相、FOC 或霍尔采样；BL50V300 已完成无感换相。
4. GPIO 编号不得凭空指定，必须放入配置结构或项目配置头文件。
5. STOP、BRAKE、DIR 的低有效特性必须在驱动内部封装。
6. 默认硬件假设是外接 N-MOS 开漏下拉，因此 MCU 输出高表示功能断言；要保留极性配置以适配其他硬件。
7. 启动时必须先将 PWM 清零并断言 STOP，禁止上电瞬间输出非零速度。
8. 切换方向前必须先停止，不允许运行中直接反向。
9. 速度变化使用可配置斜坡，禁止从 0% 突然跳到 100%。
10. FG 默认不实现闭环；只预留可选输入接口和 TODO，直到实测确认电气特性与脉冲数/转。
11. 5V 和 13V 均按驱动器输出处理，代码和接线说明中不得把它们描述为驱动板电源输入。
12. 提交前执行 `idf.py build`，报告新增文件、API、默认参数、构建结果和仍需实测的项目。

# 9. 推荐测试步骤

## 9.1 断电检查

- 核对 VCC/GND 极性。
- 核对 U/V/W 与电机三相线。
- 核对 ESP32 与驱动器控制 GND 共地。
- 确认 STOP/BRAKE/DIR 使用开漏下拉，不存在 5 V 直入 ESP32 GPIO。
- 确认 PWM 输入有下拉，复位时为 0%。

## 9.2 模式确认

- 短按板载按键。
- 指示灯闪三下，确认进入 PWM 模式。
- 断电重上电，验证模式已保存。

## 9.3 低风险通电测试

1. 使用较低电压、限流电源和空载电机。
2. 上电后确认电机不转。
3. 读取日志，确认状态为 STOPPED。
4. 释放 STOP，以 5%～10% 占空比尝试启动；若不能起转，逐步增加。
5. 记录最低可靠起转占空比。
6. 测试正常停止。
7. 电机完全停止后测试方向切换。
8. 低速测试 BRAKE，并观察电流、温升和电源电压回升。
9. 用示波器测量 PWM 频率、幅值和 FG 波形。

## 9.4 必须记录的实测参数

| 参数 | 实测结果 |
|---|---|
| PWM 模式是否掉电保存 | 待测 |
| 0% duty 是否可靠停止 | 待测 |
| 最低可靠起转占空比 | 待测 |
| duty 与转速关系 | 待测 |
| STOP 响应时间 | 待测 |

# 10. 资料中的不确定项与风险

1. “35 A 峰值”和“12 V 25 A / 24 V 12 A 额定”依赖散热、环境温度、线材和 PCB 条件，不能只凭商品标称长期满载。
2. “130,000 RPM”是商品标称的驱动能力，不是整机允许转速；机械结构和电机额定转速优先。
3. 无感无刷驱动器在低速、大负载或启动受阻时可能换相失败，软件应限制重复启动次数并监测系统异常。
4. BRAKE 可能产生较大电流或回馈能量，电源是否能吸收回馈未说明。
5. FG 参数缺失，未经测量不得直连或用于闭环控制。
6. STOP、BRAKE、DIR 的输入电流和阈值未给出，开漏器件需在实机上验证下拉能力。
7. 商品资料未提供欠压、过流、过温、堵转等保护的具体行为，软件不能假设驱动器一定具备完整保护。

# 11. 最终开发结论

BL50V300 对 ESP32 来说应被视为一个“速度命令 + 三个低有效控制信号”的外部无感 BLDC 驱动器：

- ESP32 使用一个 LEDC PWM 输出控制速度。
- 使用 STOP、BRAKE、DIR 三个逻辑控制接口。
- 三个 5 V 默认高电平输入通过开漏晶体管下拉，避免 5 V 进入 ESP32。
- 软件必须采用安全初始化、停止后换向、速度斜坡和故障安全状态。
- FG 在电气参数和脉冲数/转实测完成前不启用。

本文可直接放入项目 `docs/BL50V300.md`，供 Claude Code 在编写 `components/bl50v300` 驱动时读取。
