# 未上水演示：两级水阀与5秒投液

2026-10-31。用户确认两级水路：先GPA0给中间水箱进水，再GPA1向洗涤桶放水；
放水阀与洗衣液泵同时运行5秒。按此接入默认按钮/手势演示，语音自定义计划尚未接通。

装衣交互不变：按钮1 → 45°等待 → 再按按钮1 → 0°确认。

蠕动泵 ml/s 尚未标定，因此5秒不是已验证的毫升量。

使用现有水阀限时板测控制路径，增加仅供内置演示的5秒接口及重检，正式补水FSM不变。
未上水时不因无流量/水位信号而提前失败；仅本演示分支跳过这些门禁，未写入配置或暴露BLE开关。
