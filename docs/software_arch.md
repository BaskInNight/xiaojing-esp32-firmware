# 软件架构补充：比赛动作演示 V2

最新未上水演示增加两级补水/投液：按钮1确认装衣并回0°后，GPA0进水阀开启5秒、
关闭确认，再让GPA1转移阀与GPB7洗衣液蠕动泵各运行5秒，全部关闭确认后才搅动。
源阀与转移阀不得同时开启；示意UV保持原有演示行为。组合阶段现为19段，估算176秒，
180秒总动作时限保持。泵未标定 ml/s，只记录5000ms，不宣称对应已知毫升数。

无水阶段通过 water_service 固定5秒演示接口与 detergent_service 的原任务执行，
仍经 safety_manager，未调用HAL直接写阀。演示许可绑定程序号/generation、0°新鲜稳定姿态、
单段10秒到期时间；仅所选水阀放行，只有GPA1阶段允许并行投液。阀泵期间禁止主轴、
换位和热风启动；未知输出、失位、故障、急停、过期均拒绝。各服务保留设备端5秒关断，
排队后的演示ON也重新检查许可，父任务等待匹配终态/关闭状态才推进。

此次只对内置未上水演示跳过流量/水位门禁；正式 water_service 分批进水FSM及无流、
低流、水位满、循环/总超时逻辑未改。接水与标定后的真实定量进水尚待验收。

遥测页位置输入：绿色实心圆表示真实稳定触发，灰色实心亮边圆表示当前换位目标尚未触发，
灰色空心圆表示未触发的其他位置。标题同步显示“位置输入 目标45”等。
目标仅来自 position_service 的 MOVING/BRAKING 与真实 target，不用历史空闲目标或推算下一步；
故障、未知状态优先，BL 主轴预留霍尔不作角度目标。位置提示每 250ms 更新，
不等待普通页面 4 秒刷新；复用既有圆点和标题，不增加 LVGL 控件。

最新交互：按钮1/上挥先请求到达 45° 装衣位，然后执行器进入 `WAIT_LOAD`，
电机、热风、UV 均保持关闭。屏幕提示“装好后再按按钮1”。用户再次短按按钮1
确认后，才开始原组合演示并回 0°，后续洗涤阶段不变。按钮2仍在所有阶段停止；
下挥、按钮3停止/急停保留。装衣等待不计入组合演示的 180 秒运行时限。
程序现在是 MOVE45 → WAIT_LOAD_CONFIRM → COMPETITION_DEMO，组合步骤仍自行复核真实 45°。
确认携带程序号与 generation；提前、重复、跨程序的确认不会启动动作。
等待装衣或去装衣位途中停止，都不会额外启动回位。

2026-10-31。原组件设计与历史验收见 `xiaojing_idf_design/`。

本轮硬件修订：用户确认 GPB5 搅动主轴对齐霍尔为预留件，比赛演示暂不依赖。
`COMPETITION_DEMO_SHAFT_HOME_REQUIRED` 默认 0，开头/收尾只确认主轴停止，
不转动寻找该霍尔；桶体 45/0/90/180/270° 换位霍尔、标定、稳定姿态和超时仍必需。
下面表格中的 BL50 HOME 仅在将该编译开关恢复为 1 后执行，当前演示正常收尾仍回 45°。

设备故障显示同时采集执行器、安全管理器、急停状态。预先创建的 LVGL 顶层弹窗
在任何页面显示 E 码、原因、阶段、原始详情与检查建议；每 250ms 检查，
绕过普通页面的 4 秒刷新节流。故障解除时才隐藏，不清故障、不自动重启输出。
演示子服务失败保留原始 machine_fault_code/detail，不再把 ESP_FAIL 转成 4294967295。

`program_control` 将 BTN1 短按、上挥手转换为内置比赛程序。程序在
`wash_executor` 中占用一个不可跳过的 `STEP_COMPETITION_DEMO`；
`competition_demo.c` 协调位置、BL50、UV、耦合热风服务，未直接访问 GPIO/HAL。
每个子请求使用独立 request_id；执行器 program_id/generation 用于程序终态身份匹配。
UI 从协调器快照取得 17 个子阶段、目标姿态及实际经过时间。

| 顺序 | 动作 |
| --- | --- |
| 预检 | 已标定；输出已知 OFF；无故障/急停；电机停止；开启 UV 示意灯 |
| 归零 | 到 45°，BL50 HOME |
| 波轮 | 到 0°，40% PWM，正反交替 20 秒，停稳后另等 3 秒 |
| 滚筒 | 到 90°，30% PWM，正反交替 24 秒，停稳后另等 3 秒 |
| 脱水 | 到 180°，80% PWM 单向 12 秒（含升速），停稳后另等 3 秒 |
| 烘干 | 到 270°，热风实际确认 ON 后计 15 秒；40% PWM 翻动窗口最多 2 秒，窗口间停至少 1 秒（最后剩余窗口除外） |
| 收尾 | 热风确认 OFF，停稳 3 秒；回 45°，HOME；UV 等全部输出确认 OFF，再播“演示完成。” |

动作均等待真实服务终态，不以预算代替限位；166 秒为估计，180 秒为动作总时限。
电机使用原服务的升速、制动、停止确认。PWM 不是反馈转速，软件停止确认不等同于独立转速传感器测量。

`safety_manager` 中的演示许可绑定 program_id/generation，最多 180 秒，结束时撤销。
只豁免演示示意 UV 与运动的互斥；仅 270° 烘干阶段允许热风与低速翻动并行。
未知输出、错误姿态、未标定、故障、急停、温度无效/过期、过温、热风冷却仍拒绝。
演示期间阀、泵、独立 PTC 等无关 ON 请求拒绝；所有 OFF 请求继续放行。
UV 服务 FSM 与安全层同时检查演示许可；热风的原诊断上限 3 秒保持，内置演示请求才允许 15 秒。

下挥手、BTN2 稳定按下约 30ms 立即请求 STOP；不等待松手。BTN3 急停保留。
停止取消全部自有子请求，等待匹配终态以及输出关闭；不会自动回 45°。
关闭确认失败则进入急停/故障，不发布“演示完成”。停止按键的后续长按/松手不会误转为语音收音。
启动与结束播报由现有异步语音队列执行，不阻塞控制任务。
