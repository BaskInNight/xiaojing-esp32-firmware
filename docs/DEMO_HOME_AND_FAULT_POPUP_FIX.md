# 演示 HOME 预留件与故障弹窗修复

2026-10-31。串口 `tmp/demo_serial_test.log` 记录：程序在 18.137 秒开始到 45°，
21.947 秒进入第 2 阶段 BL50 HOME，32.587 秒执行器故障 `4294967295`。
时序与默认 10 秒 HOME 超时吻合，但旧组合层把服务故障统一返回 ESP_FAIL，原始码无法追溯。

用户明确说明搅动电机对齐霍尔是后续预留件；本次比赛演示默认跳过开头与结尾的
主轴 HOME 动作，替换为确认停止。桶体换位霍尔、真实姿态、超时、热风温度保护及
全程停止/急停不改。独立 HOME API 和原来的错误检查保留，以供后续硬件使用。

故障不显示的直接原因：原 UI 仅检查 `safety_fault/emergency_stop`，执行器自己的
FAULT 未触发故障卡片；且卡片仅在首页。修复增加 executor_fault 和统一判定，
LVGL 顶层持久弹窗跨页面显示，不受普通页面刷新节流影响。预分配控件，故障期间不重建弹窗。
弹窗不代替故障解除，也不自动恢复电机；实际解除故障后隐藏。

组合服务保留子终态 fault_code/detail，并记录服务/request/stage/ESP错误与关闭确认。
主机回归测试覆盖三类故障源、原始 HOME 超时码、详情文案、默认不需要主轴 HOME，
原有取消、姿态、输出未知、温度与超时测试继续运行。

软件编译和测试不能证明实际磁铁或安装状态；本轮跳过仅针对用户确认的预留主轴霍尔。
